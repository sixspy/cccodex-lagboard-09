# 冻结禁写说明（封档）

- 仓：`06-lagboard`（源到达SLA）
- 冻结日：2026-11-19
- 状态：已敲板、已封档；**冻结当天不许改口**
- 专册：本文件（禁写专册唯一正本）

## 一、口径

SLA 判级后 `违约` 即冻结。冻结是**写路径闸门**，不是提示：`违约` 源在冻结态下
不得新增任何到达。只改提示、冻结后仍插入到达，一律判禁写未过。

## 二、唯一写法：甲路径

冻结禁写只能走冻结源禁写入库门闩写法中的**一种**。本仓敲定**甲路径**，乙路径不采用，
**甲乙两径不得混用**。

甲路径：冻结态下 `POST /api/arrivals` 在同一事务内 `BEGIN IMMEDIATE` 取得禁写锁、
读取该源态并锁行；判为冻结则**拒绝插入**，并在同事务内记审计与任务，提交后才返回
`409`。冻结源正式到达零新增。

- 未采用乙路径：不做“带版本戳条件更新、拒绝过期写入”的写法。
- 落点：`backend/app.py` 的 `write_tx()` 与 `add_arrival()`；`write_tx()` 是本仓唯一写口。

## 三、台账与读面

库文件放在禁写仓区：`data/freeze/app.db`（不是 `data/app.db`）。台账与到达同库，
门闩才能同事务。

| 读面 | 接口 / 位置 | 同态要求 |
|------|-------------|----------|
| 源目录 | `GET /api/sources` | 冻结源 `output_mode=冻结` |
| 到达流水 | `GET /api/arrivals` | 冻结期零新增 |
| 审计附页 | `GET /api/freeze/audit` | 有 `冻结禁写` 等留痕 |
| 水位页 | `GET /api/freeze/watermarks` | 与源目录同态，冻结期水位不越过 |
| 任务列表 | `GET /api/freeze/tasks` | 有 `拒写` / `争用` / `偏了` / `入库` |

页面：入库入口挂在“到达登记”时限台菜单，**不另起禁写台**；禁写台账（审计附页 /
水位页 / 任务列表）挂在同一页的“冻结台账”菜单。

## 四、留痕口径

- `冻结禁写`：甲路径主留痕，冻结态拒插。
- `冻结禁写争用`：采集双路同时打冻结源，须占禁写锁；后交只记争用，仍零新增。
- `禁写偏了`：偏离本说明的绕写（如 `force`）一律驳回，并留此痕。
- `解冻`：`补齐恢复` 后整源解冻为可写，水位恢复前进。

## 五、口令与权限

口令沿用本仓禁写侧：登录后以 `Bearer` 令牌调用，未登录一律 401。
冻结态的拒绝不因角色放宽。

## 六、验收顺序（不可跳步）

1. 先复现：冻结源仍写入新到达（改前必须见底）。
2. 落**禁写失败测**：冻结源写入成功须红。
3. 落**双路抢插失败测**：缺“冻结禁写争用”留痕须红。
4. 两测均见红后，才准改禁写写路径。
5. 收尾：入库五处同态可读。

对应测：`tests/test_freeze_gate.py`。

## 七、偏离即驳回

与本节口径不符的实现一律驳回，并在审计附页留下 `禁写偏了`。
只改提示不改写路径，判**禁写未过**。
